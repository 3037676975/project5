PROJECT5 · API 小白学习版

不会写代码也能先看懂：Project5 API 到底怎么调用？

你不用先学会后端、HTTP、JSON。先把 API 理解成“两个程序之间办事的窗口”。看完这页，你至少会知道：API Key 是什么、为什么先拿 task_id、什么时候才能拿到 audio_url，以及怎样把整段说明直接交给 AI 帮你完成接入。

默认推荐记忆名ETG1
真实 API voicezh-TW-YunJheNeural
声音Edge 云哲 · 台湾男声
推荐语速1.10
最重要的一点：ETG1 是方便记忆的推荐名，不是 API 参数。真正发给 Project5 的 voice 必须是 zh-TW-YunJheNeural。

1. API 是什么？

假设你以后做一个 AI 视频项目。视频项目需要配音，但它不应该自己重新安装一套 TTS。它只把文字交给 Project5，然后等 Project5 返回音频。

你的业务项目→提交文字→Project5→生成语音→audio_url
一句话：Project5 专门负责语音，其他项目只负责“调用”。

2. 先认识 6 个最重要的词

BASE_URLProject5 的地址，相当于店铺地址。
API Key调用权限通行证。
Endpoint具体功能窗口，例如 /v1/audio/speech。
POST向服务器提交一件事情。
JSON提交给服务器的一张参数表。
task_id任务取件号，用它继续查询进度。

3. 调用前只准备两个东西

1
Project5 地址
PROJECT5_BASE_URL=http://YOUR_PROJECT5_HOST

以后所有接口都从这个地址开始。

2
API Key

Project5 后台左侧进入「API 密钥」→ 创建密钥 → 保存完整 Key。

PROJECT5_API_KEY=YOUR_API_KEY

请求时使用：Authorization: Bearer YOUR_API_KEY

真实 API Key 不要写进公开 GitHub、浏览器前端、公开截图或日志。

4. 第一次请求直接照着这个写

先不要研究其他音色。第一次接通业务，默认使用 ETG1 对应的 Edge 云哲台湾男声和 1.10 语速。

POST /v1/audio/speech Authorization: Bearer YOUR_API_KEY Content-Type: application/json { "input": "你好，这是 Project5 API 的第一次测试。", "engine": "edge", "voice": "zh-TW-YunJheNeural", "speed": 1.10 }
参数意思第一次推荐
input要朗读的文字你的文本
engineTTS 引擎edge
voice声音 IDzh-TW-YunJheNeural
speed语速1.10

5. 为什么不是马上返回 MP3？

因为生成语音可能需要几秒或更久。Project5 用的是“异步任务”：先接单，再让你的程序拿任务号查询。

POST→HTTP 202→task_id→GET 查询→completed→audio_url
202 Accepted 只代表“任务已经接收”，不代表“音频已经生成完成”。

6. POST 后你会拿到一个 task_id

{ "id": "tts_20260907_xxxxxxxxxx", "status": "queued", "engine": "edge", "voice": "zh-TW-YunJheNeural" }

其中最重要的是 id。把它理解成快递取件号，后面要靠它查进度。

7. 用 task_id 查询任务

GET /v1/tasks/tts_20260907_xxxxxxxxxx Authorization: Bearer YOUR_API_KEY
状态程序应该做什么
queued等大约 1 秒，再查一次
processing继续等待
completed读取 audio_url
failed停止轮询，读取 error

程序必须有总超时，比如 180 秒，不要无限查询。

8. completed 后才真正拿到音频

{ "id": "tts_20260907_xxxxxxxxxx", "status": "completed", "engine": "edge", "voice": "zh-TW-YunJheNeural", "audio_url": "http://YOUR_PROJECT5_HOST/audio/tts_20260907_xxxxxxxxxx.mp3" }

audio_url 才是最终成品地址。你的项目可以播放、下载、长期转存，或者继续交给视频合成程序。

9. 一句话记住整个 API

API Key = 通行证 POST = 下单 202 = 已接单 id = 取件号 GET /v1/tasks/{id} = 查进度 audio_url = 最终成品

10. curl 第一次测试

提交任务
curl -X POST "$PROJECT5_BASE_URL/v1/audio/speech" \ -H "Authorization: Bearer $PROJECT5_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "input": "你好，这是 Project5 API 的第一次测试。", "engine": "edge", "voice": "zh-TW-YunJheNeural", "speed": 1.10 }'

返回 id 后，再查询：

curl \ -H "Authorization: Bearer $PROJECT5_API_KEY" \ "$PROJECT5_BASE_URL/v1/tasks/你的task_id"

11. Python 完整最小示例

这段代码已经包含提交、保存 task_id、轮询和取得 audio_url 的完整流程。

import os import time import requests BASE_URL = os.environ["PROJECT5_BASE_URL"].rstrip("/") API_KEY = os.environ["PROJECT5_API_KEY"] HEADERS = {"Authorization": f"Bearer {API_KEY}"} def submit_tts(text, voice="zh-TW-YunJheNeural", speed=1.10): r = requests.post( f"{BASE_URL}/v1/audio/speech", headers={**HEADERS, "Content-Type": "application/json"}, json={ "input": text, "engine": "edge", "voice": voice, "speed": speed, }, timeout=15, ) r.raise_for_status() return r.json()["id"] def wait_for_task(task_id, timeout_seconds=180): deadline = time.time() + timeout_seconds while time.time() < deadline: r = requests.get( f"{BASE_URL}/v1/tasks/{task_id}", headers=HEADERS, timeout=10, ) r.raise_for_status() data = r.json() if data["status"] == "completed": return data["audio_url"] if data["status"] == "failed": raise RuntimeError(data.get("error") or data) time.sleep(1) raise TimeoutError("Project5 TTS task timeout") task_id = submit_tts("你好，这是 Project5 API 测试。") print(wait_for_task(task_id))

12. Edge 和 Kokoro 怎么选？

引擎怎么理解建议
Edge在线语音，需要服务器联网，通常输出 MP3第一次接入默认推荐
Kokoro本地 CPU 推理，通常输出 WAV需要本地生成或指定 Kokoro 音色时

如果要换其他音色，先查真实 ID：

GET /v1/voices?engine=edge GET /v1/voices?engine=kokoro

13. 常见错误

现象先检查
401 / 403API Key、Bearer、Key 是否启用
400 Unknown voice不要传 ETG1；传 zh-TW-YunJheNeural
一直 queued / processing继续轮询，但设置总超时；同时查看后台生成任务
status=failed读取 error，不要只显示“失败”
audio_url 以后失效检查后台是否开启 24 小时自动清理；需要长期保存就及时转存
