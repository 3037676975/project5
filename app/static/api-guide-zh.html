API 中文入门：从“什么是 API”到真正调用 TTS

适合第一次接触 API。看完以后，你应该能理解 API Key、POST、JSON、task_id、轮询和 audio_url 分别在做什么。

1. API 是什么？

API 可以理解为“程序之间办事的窗口”。你的 AI 视频程序不需要知道 Kokoro 模型怎么加载，只需要把文字交给 Project5，然后拿回生成结果。

你的 AI 视频项目
↓ 提交文字
Project5 TTS API
↓ 返回任务编号 task_id
你的项目查询任务进度
↓
拿到 audio_url
↓
继续合成视频
一句话：Project5 把“语音生成”封装成一个独立服务，其他项目只负责调用它。

2. 一次 API 请求由哪些部分组成？

POST /v1/audio/speech Authorization: Bearer YOUR_API_KEY Content-Type: application/json { "input": "今天学习 ChatGPT and LangChain，然后继续中文。", "engine": "kokoro", "voice": "zf_001", "speed": 1.0 }
部分意思
POST提交数据，让服务器执行一件事
/v1/audio/speech语音生成这个功能的地址
Authorization身份认证
Bearer API_KEY你的调用通行证
JSON你交给服务器的参数表单

3. 为什么先返回 task_id，而不是直接返回音频？

TTS 可能需要几秒甚至更久，所以 Project5 使用异步任务。

POST /v1/audio/speech
↓
HTTP 202 + task_id
↓
GET /v1/tasks/{id}
↓
queued → processing → completed
↓
读取 audio_url

202 Accepted 的意思是“任务已经接收”，不是“已经生成完成”。

4. 获取音色

Kokoro

GET /v1/voices?engine=kokoro

Edge

GET /v1/voices?engine=edge

后台音色表里的 API ID，例如 zf_001，就是请求里的 voice。

5. Kokoro 调用

POST /v1/audio/speech Authorization: Bearer YOUR_API_KEY Content-Type: application/json { "input": "你好，today we test ChatGPT，然后继续中文。", "engine": "kokoro", "voice": "zf_001", "speed": 1.0 }

Kokoro 在服务器本地 CPU 推理，最终生成 WAV。

6. Edge 调用

POST /v1/audio/speech Authorization: Bearer YOUR_API_KEY Content-Type: application/json { "input": "你好，这是 Edge TTS 测试。", "engine": "edge", "voice": "zh-CN-XiaoxiaoNeural", "speed": 1.0 }

Edge 需要服务器联网，最终生成 MP3。

7. 查询任务

GET /v1/tasks/TASK_ID Authorization: Bearer YOUR_API_KEY

完成以后会看到类似：

{ "id": "tts_...", "status": "completed", "engine": "kokoro", "voice": "zf_001", "audio_url": "http://YOUR_HOST/audio/tts_....wav" }

8. Python 完整示例

import time import requests BASE_URL = "http://YOUR_HOST" API_KEY = "YOUR_API_KEY" headers = {"Authorization": f"Bearer {API_KEY}"} r = requests.post( f"{BASE_URL}/v1/audio/speech", headers=headers, json={ "input": "今天学习 ChatGPT and LangChain，然后继续中文。", "engine": "kokoro", "voice": "zf_001", "speed": 1.0, }, timeout=30, ) r.raise_for_status() task_id = r.json()["id"] while True: task = requests.get( f"{BASE_URL}/v1/tasks/{task_id}", headers=headers, timeout=30, ).json() if task["status"] == "completed": print(task["audio_url"]) break if task["status"] == "failed": raise RuntimeError(task.get("error")) time.sleep(1)

9. 固定试听与正式音频

类型用途保存策略
固定试听比较音色、写备注永久保存，不参与 24h 清理
正式生成音频视频、播客真正使用手动清理，或开启 24h 自动清理

10. 常见状态码

状态含义
200请求成功
202任务已接收，正在异步处理
400参数错误，例如 voice 不存在
401API Key 不正确
404任务或音频不存在
500服务器内部错误
不要把真正的 API Key 写到 GitHub 公共仓库，也不要直接写在公开网页 JavaScript 里。正式项目最好由你自己的后端保存 Key。

11. 最后记住这 7 个词

API Key = 通行证
Endpoint = 办事窗口
POST = 提交任务
JSON = 参数表单
202 + task_id = 取件号
GET /v1/tasks/{id} = 查进度
audio_url = 最终结果
